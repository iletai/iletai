### 💡 Core Engineering Philosophy

> **"Deterministic clients, decoupled backends, observable telemetry."**
- **Deterministic Client State:** Xây dựng ứng dụng iOS module hóa với Swift Concurrency &amp; TCA, loại bỏ hoàn toàn race-conditions và tối ưu render lifecycle.
- **Event-Driven Cloud Backends:** Kiến trúc AWS Serverless tối ưu hóa throughput, cold-start tối thiểu, single-table DynamoDB cho độ trễ sub-millisecond.
- **Stress-Tested Reliability:** Kiểm thử tải nghiêm ngặt bằng Apache JMeter &amp; k6 nhằm đảm bảo hệ thống đạt chuẩn P99 SLA trước khi ra production.
